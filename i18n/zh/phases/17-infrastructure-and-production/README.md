# Phase 17: 基础设施与生产环境

> 将 AI 部署到真实世界。扩展、监控、优化。

## 在 GitHub 上开始本阶段

**前置要求：** Phase 11 LLM Engineering 和 Phase 13 Tools and Protocols。

**第一课：** [Managed LLM Platforms](01-managed-llm-platforms/)

从仓库根目录运行以下命令：

```bash
python3 phases/17-infrastructure-and-production/01-managed-llm-platforms/code/main.py
```

保留命令、退出码、成本与延迟对比、冗余提升幅度，以及一份简短的决策记录，说明你选择背后的工作负载假设。

**下一步操作：** 更改一个工作负载或 SLA 输入，解释新的选择，然后继续学习 [Inference Platform Economics](02-inference-platform-economics/)。

浏览 [Phase 17 完整课程列表](../../README.md#phase-17) 或 [跨阶段路线图](../../ROADMAP.md)。

# 阶段 8：生成式 AI

> 创建图像、视频、音频、3D 模型等更多内容。

## 在 GitHub 上开始此阶段

**前置知识：** 阶段 2 机器学习基础、阶段 3 深度学习核心，以及
阶段 7 第 14 课《从零构建 Transformer》。

**第一堂课：** [生成模型的分类与历史](01-generative-models-taxonomy-history/)

从仓库根目录运行以下命令：

```bash
python3 phases/08-generative-ai/01-generative-models-taxonomy-history/code/main.py
```

保留命令、退出码、密度估计、生成的样本，以及一句解释隐式生成器无法回答的关于 `p(x)` 的内容。

**下一步：** 更改随机种子，比较密度估计，然后继续学习 [自编码器与变分自编码器](02-autoencoders-vae/)。

浏览 [阶段 8 完整课程列表](../../README.md#phase-8) 或
[跨阶段路线图](../../ROADMAP.md)。

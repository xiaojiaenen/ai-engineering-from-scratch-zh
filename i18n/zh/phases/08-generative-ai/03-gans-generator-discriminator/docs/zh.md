# 生成对抗网络 — 生成器 vs 判别器

> 古德费洛在 2014 年的技巧是完全跳过密度建模。两个网络。一个造假样本，一个识假。它们对抗直到假样本与真样本无法区分。这本不该奏效。很多时候确实没奏效。但当它奏效时，样本仍然是该领域文献中最锐利的。

**类型：** 构建
**语言：** Python
**前置知识：** 阶段 3 · 02（反向传播）、阶段 3 · 08（优化器）、阶段 8 · 02（VAE）
**时间：** 约 75 分钟

## 问题

VAE 产生的样本模糊，因为其 MSE 解码器损失对*均值*图像是贝叶斯最优的——而许多合理数字的均值是一个模糊的数字。你想要一个奖励*合理性*而非与任何单一目标的逐像素接近的损失。合理性没有闭式解。你必须学习它。

古德费洛的想法：训练一个分类器 `D(x)` 来区分真实图像和伪造图像。训练一个生成器 `G(z)` 来欺骗 `D`。`G` 的损失信号就是 `D` 当前认为什么看起来像真实的。随着 `G` 的改进，这个信号也在变化，追赶着一个移动的目标。如果两个网络都收敛，`G` 就学会了数据分布，而从未写下 `log p(x)`。

这是对抗训练。其数学是一个极小极大博弈：

```
min_G max_D  E_real[log D(x)] + E_fake[log(1 - D(G(z)))]
```

在 2026 年，GAN 已不再是 SOTA 生成器（扩散模型和流匹配夺走了这一桂冠）。但 StyleGAN 2/3 仍然是有史以来最锐利的人脸模型，GAN 判别器被用作扩散训练中的*感知损失*，而对抗训练支撑了快速 1 步蒸馏（SDXL-Turbo、SD3-Turbo、LCM），让你能够交付实时扩散。

## 概念

![GAN 训练：生成器和判别器在极小极大博弈中](../assets/gan.svg)

**生成器 `G(z)`。** 将噪声向量 `z ~ N(0, I)` 映射为样本 `x̂`。一个解码器形状的网络（全连接或转置卷积）。

**判别器 `D(x)`。** 将样本映射为标量概率（或分数）。真实 → 1，伪造 → 0。

**损失。** 两个交替更新：

- **训练 `D`：** `loss_D = -[ log D(x) + log(1 - D(G(z))) ]`。真实=1、伪造=0 的二元交叉熵。
- **训练 `G`：** `loss_G = -log D(G(z))`。这是古德费洛使用的*非饱和*形式（原始的 `log(1 - D(G(z)))` 会在 `D` 自信时饱和并扼杀梯度）。

**训练循环。** 一步 `D`，一步 `G`。重复。

**为何有效。** 如果 `G` 完美匹配 `p_data`，则 `D` 无法做得比随机更好，处处输出 0.5；`G` 得不到更多梯度。达到平衡。

**为何失效。** 模式崩溃（`G` 找到一个 `D` 无法分类的模式并无限复制）、梯度消失（`D` 学得太快，`log D` 饱和）、训练不稳定性（学习率、批次大小、一切皆可）。

## 让 GAN 生效的变体

| 年份 | 创新 | 修复 |
|------|------|------|
| 2015 | DCGAN | 卷积/反卷积、批归一化、LeakyReLU——第一个稳定架构。 |
| 2017 | WGAN、WGAN-GP | 用 Wasserstein 距离 + 梯度惩罚替代 BCE。修复梯度消失。 |
| 2017 | 谱归一化 | 对判别器施加 Lipschitz 约束。2026 年的判别器仍在使用。 |
| 2018 | 渐进式 GAN | 先训练低分辨率，逐步添加层。首个兆像素级结果。 |

| 2021 | StyleGAN3 | 无混叠、平移等变——2026 年仍为人脸黄金标准。 |

| 2024 | R3GAN | 更强的正则化重新包装；在 1024² 上无需技巧即可工作。 |

## 构建它

`code/main.py` 在 1-D 数据（两个高斯混合）上训练一个小型 GAN。生成器和判别器都是单隐藏层 MLP。我们手动实现前向、反向和极小极大循环。目标是观察两个关键失效模式（模式崩溃 + 梯度消失）是如何发生的。

### 步骤 1：非饱和损失

古德费洛的原始损失 `log(1 - D(G(z)))` 当 `D` 以高置信度将 `G` 的伪造判为假时会趋向 0。此时 `G` 的梯度几乎为零——`G` 无法改进。非饱和形式 `-log D(G(z))` 有相反的渐近行为：当 `D` 自信时它会发散，给 `G` 强烈的信号。

```python
def g_loss(d_fake):
    # 最大化 log D(G(z))  <=>  最小化 -log D(G(z))
    return -sum(math.log(max(p, 1e-8)) for p in d_fake) / len(d_fake)
```

### 步骤 2：每步生成器对应一步判别器

```python
for step in range(steps):
    # 训练 D
    real_batch = sample_real(batch_size)
    fake_batch = [G(z) for z in sample_noise(batch_size)]
    update_D(real_batch, fake_batch)

    # 训练 G
    fake_batch = [G(z) for z in sample_noise(batch_size)]  # 新鲜伪造
    update_G(fake_batch)
```

给 `G` 新鲜伪造样本，否则梯度会过时。

### 步骤 3：监控模式崩溃

```python
if step % 200 == 0:
    samples = [G(z) for z in sample_noise(500)]
    mode_a = sum(1 for s in samples if s < 0)
    mode_b = 500 - mode_a
    if min(mode_a, mode_b) < 50:
        print("  [!] 模式崩溃：一个模式被饿死")
```

典型症状：两个真实模式中的一个停止被生成。判别器停止纠正它，因为它从未被当作假样本出现过。

## 陷阱

- **判别器太强。** 将 `D` 的学习率降低 2-5 倍，或添加实例/层噪声。如果 `D` 准确率超过 95%，`G` 就死了。
- **生成器记住一个模式。** 向 `D` 输入添加噪声，使用小批量判别层，或切换到 WGAN-GP。
- **批归一化泄露统计。** 真实批次 + 伪造批次流经同一个 BN 层会混合它们的统计量。改用实例归一化或谱归一化。
- **Inception 分数作弊。** FID 和 IS 在低样本数时噪声很大。评估时使用 ≥10k 样本。
- **一次性采样对条件任务是谎言。** 你仍然需要 CFG 尺度、截断技巧和重采样才能获得可用输出。

## 使用它

2026 年的 GAN 技术栈：

| 场景 | 选择 |
|------|------|
| 固定姿势的照片级人脸 | StyleGAN3（最锐利，最小） |
| 动漫 / 风格化人脸 | StyleGAN-XL 或 Stable Diffusion LoRA |
| 图像到图像翻译 | Pix2Pix / CycleGAN（阶段 8 · 04）或 ControlNet（阶段 8 · 08） |
| 快速 1 步文本到图像 | 扩散对抗蒸馏（SDXL-Turbo、SD3-Turbo） |
| 扩散训练器内的感知损失 | 小 GAN 判别器作用于图像裁剪 |
| 任何多模态、开放式任务 | 不要——改用扩散或流匹配 |

GAN 锐利但狭窄。一旦你的领域展开——照片、任意文本提示、视频——切换到扩散模型。对抗技巧作为组件存活下来（感知损失、蒸馏），而非独立的生成器。

## 练习

1. **简单。** 用默认设置运行 `code/main.py`。然后设置 `D_LR = 5 * G_LR` 并重新运行。`G` 的损失要多快就坍缩到常数？
2. **中等。** 用 WGAN 损失替换古德费洛 BCE 损失：`loss_D = E[D(fake)] - E[D(real)]`，`loss_G = -E[D(fake)]`，并将 `D` 的权重裁剪到 `[-0.01, 0.01]`。训练是否更稳定？比较墙钟收敛速度。
3. **困难。** 将 1-D 示例扩展到 2-D 数据（环上的 8 个高斯混合）。追踪生成器在 1k、5k、10k 步中捕获了多少个模式。实现小批量判别并重新测量。

## 术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|---------|
| 生成器 | "G" | 噪声到样本网络，`G: z → x̂`。 |
| 判别器 | "D" | 分类器 `D: x → [0, 1]`，真 vs 假。 |
| 极小极大 | "游戏" | 联合目标的 `min_G max_D`。 |
| 非饱和损失 | "修复" | 对 `G` 使用 `-log D(G(z))` 而非 `log(1 - D(G(z)))`。 |
| 模式崩溃 | "G 记住了一个东西" | 尽管数据多样，生成器只产生少量不同输出。 |
| WGAN | "Wasserstein" | 用 Earth-Mover 距离 + 梯度惩罚替代 BCE；更平滑的梯度。 |
| 谱归一化 | "Lipschitz 技巧" | 约束 `D` 的权重范数以限制其斜率；稳定训练。 |
| StyleGAN | "那个能工作的" | 映射网络 + AdaIN；人脸领域最佳，2026 年仍在用。 |

## 生产笔记：一次性推理是 GAN 的持久优势

GAN 在开放域生成的样本质量上已不再胜出，但在推理成本上仍然领先。在生产推理的文献术语中，GAN 具有：

- **无前处理、无解码阶段。** 单次 `G(z)` 前向传递。TTFT ≈ 总延迟。
- **无 KV 缓存压力。** 唯一的状态是权重。批次大小受激活内存限制，而非缓存。
- **平凡的连续批处理。** 由于每个请求消耗相同固定的 FLOPs，服务器目标占用的静态批次通常是最优的。无需飞行中调度器。

这就是为什么 GAN 蒸馏（SDXL-Turbo、SD3-Turbo、ADD、LCM）是 2026 年快速文本到图像的占主导技术：它将 20-50 步扩散流水线压缩为 1-4 次类 GAN 前向传递，同时保持扩散基座的分布。对抗损失作为训练时的旋钮存活下来，用于将慢速生成器转为快速生成器。

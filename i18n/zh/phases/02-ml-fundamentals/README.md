# Phase 2: ML Fundamentals

> Classical machine learning is still the backbone of most production AI.

## 在 GitHub 上开始本阶段

**前置要求：** Phase 1 数学基础与 NumPy。使用以下命令验证学习路线：
`python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route ml-foundations`。

**第一课：** [What Is Machine Learning](01-what-is-machine-learning/)

从仓库根目录运行以下命令：

```bash
python3 phases/02-ml-fundamentals/01-what-is-machine-learning/code/ml_intro.py
```

记录该命令、退出码、测试准确率、随机基线，以及一句话说明为何学到的分类器优于该基线。

**下一步操作：** 更改类别分隔方式，预测准确率将如何变化，重新运行后继续进入 [Linear Regression from Scratch](02-linear-regression/)。

浏览 [Phase 2 完整课程列表](../../README.md#phase-2) 或 [跨阶段路线图](../../ROADMAP.md)。

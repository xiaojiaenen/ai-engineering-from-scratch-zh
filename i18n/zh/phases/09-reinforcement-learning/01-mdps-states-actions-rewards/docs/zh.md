# MDP、状态、动作与奖励

> 一个马尔可夫决策过程由五个要素组成：状态、动作、转移、奖励、折扣。强化学习中的所有内容——Q-learning、PPO、DPO、GRPO——都是针对这一结构进行优化的。学一次，后续整个强化学习部分都可以免费获得。

**类型：** 学习
**语言：** Python
**前置知识：** 阶段 1 · 06（概率与分布）、阶段 2 · 01（机器学习分类）
**时间：** 约 45 分钟

## 问题所在

你在编写一个国际象棋机器人。或者一个库存规划器。或者一个交易代理。又或者一个训练推理模型的 PPO 循环。四个不同领域，一个惊人的事实：它们都坍缩成同一个数学对象。

监督学习给你 `(x, y)` 对，让你拟合一个函数。强化学习没有标签——只有一个状态流、你采取的动作序列，以及一个标量奖励。这步棋赢了吗？补货决策省到钱了吗？这笔交易盈利了吗？LLM 刚生成的 token 让评审模型的奖励更高了吗？

在你形式化它之前，无法从这个流中学习。"我看到了什么"、"我做了什么"、"接下来发生了什么"、"这有多好"——每一个都必须成为你可以推理的对象。这个形式化就是马尔可夫决策过程。本阶段的所有 RL 算法，包括结尾的 RLHF 和 GRPO 循环，都是针对这一结构进行优化的。

## 概念

![马尔可夫决策过程：状态、动作、转移、奖励、折扣](../assets/mdp.svg)

**五个要素。**

- **状态** `S`。智能体需要决策的所有信息。在 GridWorld 中是方格。在国际象棋中是棋盘。在 LLM 中是上下文窗口加上任何记忆。
- **动作** `A`。可选的动作。向上/下/左/右移动。走一步棋。生成一个 token。
- **转移** `P(s' | s, a)`。给定状态 `s` 和动作 `a`，下一状态的分布。国际象棋中是确定性的，库存管理中是随机的，LLM 解码中几乎是确定性的。
- **奖励** `R(s, a, s')`。标量信号。赢 = +1，输 = -1。收入减成本。GRPO 中的对数似然比项。
- **折扣** `γ ∈ [0, 1)`。未来奖励与当前奖励的权重。`γ = 0.99` 对应约 100 步视界；`γ = 0.9` 对应约 10 步。

**马尔可夫性质** `P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, …, s_t, a_t)`。未来仅取决于当前状态。如果不满足，则是状态表示不完整——不是方法的失败，而是状态的失败。

**策略与回报。** 策略 `π(a | s)` 将状态映射为动作分布。回报 `G_t = r_t + γ r_{t+1} + γ² r_{t+2} + …` 是未来奖励的折扣求和。值函数 `V^π(s) = E[G_t | s_t = s]` 是在策略 `π` 下从 `s` 出发的期望回报。Q 值 `Q^π(s, a) = E[G_t | s_t = s, a_t = a]` 是从特定动作开始的期望回报。每个 RL 算法都估计这两种之一，然后相应地改进 `π`。

**贝尔曼方程。** 本阶段所有内容使用的不动点方程：

`V^π(s) = Σ_a π(a|s) Σ_{s', r} P(s', r | s, a) [r + γ V^π(s')]`
`Q^π(s, a) = Σ_{s', r} P(s', r | s, a) [r + γ Σ_{a'} π(a'|s') Q^π(s', a')]`

这些方程将期望回报分解为"当前这一步的奖励"加上"着陆点的折扣值"。递归的。阶段 9 的每个算法要么迭代此方程直至收敛（动态规划），要么从中采样（蒙特卡洛），要么单步自举（时序差分）。

## 动手实现

### 步骤 1：一个简单的确定性 MDP

一个 4×4 的 GridWorld。智能体从左上角开始，终点在右下角，每步奖励为 -1，动作集合为 `{up, down, left, right}`。参见 `code/main.py`。

```python
GRID = 4
TERMINAL = (3, 3)
ACTIONS = {"up": (-1, 0), "down": (1, 0), "left": (0, -1), "right": (0, 1)}

def step(state, action):
    if state == TERMINAL:
        return state, 0.0, True
    dr, dc = ACTIONS[action]
    r, c = state
    nr = min(max(r + dr, 0), GRID - 1)
    nc = min(max(c + dc, 0), GRID - 1)
    return (nr, nc), -1.0, (nr, nc) == TERMINAL
```

五行。这就是整个环境。确定性转移、恒定步惩罚、吸收态终点。

### 步骤 2： rollout 一个策略

策略是从状态到动作分布的函数。最简单的：均匀随机。

```python
def uniform_policy(state):
    return {a: 0.25 for a in ACTIONS}

def rollout(policy, max_steps=200):
    s, total, steps = (0, 0), 0.0, 0
    for _ in range(max_steps):
        a = sample(policy(s))
        s, r, done = step(s, a)
        total += r
        steps += 1
        if done:
            break
    return total, steps
```

运行随机策略 1000 次。对于 4×4 棋盘，平均回报大约在 -60 到 -80 之间。最优回报是 -6（沿对角线向下向右的直线路径）。缩小这个差距就是阶段 9 的全部内容。

### 步骤 3：通过贝尔曼方程精确计算 `V^π`

对于小型 MDP，贝尔曼方程是一个线性方程组。枚举状态，应用期望，迭代直到值不再变化。

```python
def policy_evaluation(policy, gamma=0.99, tol=1e-6):
    V = {s: 0.0 for s in all_states()}
    while True:
        delta = 0.0
        for s in all_states():
            if s == TERMINAL:
                continue
            v = 0.0
            for a, pi_a in policy(s).items():
                s_next, r, _ = step(s, a)
                v += pi_a * (r + gamma * V[s_next])
            delta = max(delta, abs(v - V[s]))
            V[s] = v
        if delta < tol:
            return V
```

这是策略迭代评估。它是 Sutton & Barto 中的第一个算法，也是后续所有 RL 方法的理论基础。

### 步骤 4：`γ` 是一个具有物理意义的超参数

有效视界大约为 `1 / (1 - γ)`。`γ = 0.9` → 10 步。`γ = 0.99` → 100 步。`γ = 0.999` → 1000 步。

太低则智能体短视。太高则信用分配变得嘈杂，因为许多早期步骤共同承担远未来奖励的责任。LLM RLHF 通常使用 `γ = 1`，因为剧集短暂且有界。控制任务使用 `0.95–0.99`。长视界策略游戏使用 `0.999`。

## 陷阱

- **非马尔可夫状态。** 如果你需要最近三次观测来决定，那么"状态"不仅仅是当前观测。修复：堆叠帧（DQN 在 Atari 上堆叠 4 帧）或使用循环状态（在观测上运行 LSTM/GRU）。
- **稀疏奖励。** 只有胜负的奖励在大型状态空间中几乎无法学习。塑造奖励（中间信号）或通过模仿进行自举（阶段 9 · 09）。
- **奖励黑客。** 优化代理奖励往往会产生病态行为。OpenAI 的赛艇代理一直在原地转圈收集能量道具，而不是完成比赛。始终从目标结果定义奖励，而非代理指标。
- **折扣设定错误。** `γ = 1` 在无限视界任务上会使所有值趋于无穷。始终用有限视界或 `γ < 1` 来限制。
- **奖励尺度。** {+100, -100} 与 {+1, -1} 的奖励给出相同的最优策略，但梯度幅度差异巨大。在传入 PPO/DQN 前归一化到 `[-1, 1]` 左右。

## 使用它

2026 年的技术栈在进入代码之前先将每个 RL 管道简化为 MDP：

| 场景 | 状态 | 动作 | 奖励 | γ |
|-----------|-------|--------|--------|---|
| 控制（运动、操作） | 关节角度 + 速度 | 连续力矩 | 任务特定的塑造奖励 | 0.99 |
| 游戏（国际象棋、围棋、扑克） | 棋盘 + 历史 | 合法走法 | 赢=+1 / 输=-1 | 1.0（有限） |
| 库存/定价 | 库存 + 需求 | 订购数量 | 收入 - 成本 | 0.95 |
| LLM 的 RLHF | 上下文 token | 下一个 token | 末尾的奖励模型评分 | 1.0（剧集约 200 token） |
| 推理的 GRPO | 提示 + 部分响应 | 下一个 token | 末尾的验证器 0/1 | 1.0 |

在编写任何训练循环之前，先写出五个元组。大多数"RL 不起作用"的错误报告最终都追溯到纸面上就存在问题的 MDP 表述。

## 练习

1. **简单。** 在 `code/main.py` 中实现 4×4 GridWorld 和随机策略 rollout。运行 10,000 集。报告回报的均值和标准差。与最优回报（-6）比较。
2. **中等。** 对均匀随机策略运行 `policy_evaluation`，取 `γ ∈ {0.5, 0.9, 0.99}`。为每种情况将 `V` 打印为 4×4 网格。解释为什么靠近终点的状态值随着更大的 `γ` 增长更快。
3. **困难。** 将 GridWorld 变为随机：每个动作以概率 `p = 0.1` 滑向相邻方向。重新评估均匀策略。`V[start]` 变好还是变差？为什么？

## 关键术语

| 术语 | 人们说什么 | 实际含义 |
|------|--------------------------|--------------------------|
| MDP | "强化学习框架" | 满足马尔可夫性质的元组 `(S, A, P, R, γ)`。 |
| 状态 | "智能体看到的内容" | 在所选策略类下对未来动力学的充分统计量。 |
| 策略 | "智能体的行为" | 条件分布 `π(a \| s)` 或确定性映射 `s → a`。 |
| 回报 | "总奖励" | 从当前步骤起的折扣求和 `Σ γ^t r_t`。 |
| 值 | "一个状态有多好" | 在 `π` 下从 `s` 开始的期望回报。 |
| Q 值 | "一个动作有多好" | 在 `π` 下从 `s` 出发、第一步动作是 `a` 的期望回报。 |
| 贝尔曼方程 | "动态规划递归" | 将值/Q 分解为单步奖励加折扣后继值的不动点方程。 |
| 折扣 `γ` | "未来 vs 现在" | 对远未来奖励的几何权重；有效视界 `~1/(1-γ)`。 |

# 心智社会与多智能体辩论

> 明斯基（Minsky）1986年的前提假设——智能是专家的“社会”——每隔十年便会被重新发现一次。2023年，杜等人（Du et al.）将其转化为一种具体的算法：多个 LLM 实例提出答案，阅读彼此的答案，进行批评与更新。经过 N 轮迭代，它们收敛于一个共识，在六项推理与事实性任务上均优于零样本思维链（zero-shot CoT）和反思（reflection）。两项发现至关重要：**多智能体**与**多轮交互**各自独立地贡献了提升效果。这种“社会”胜过单智能体独白；多轮交互胜过单次投票。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 16 阶段 · 04（原始模型）
**预计时间：** 约 60 分钟

## 问题

自洽性（Self-consistency）——对单一模型多次采样并取多数投票结果——是你能够加装的、成本最低的推理增强手段。它有效，但很快会达到瓶颈。即使将采样数翻倍，也可能看不到任何有意义的提升。

辩论打破了这种饱和瓶颈。不再是单一模型的 N 次独立采样，而是 N 个智能体相互阅读推理过程并进行修正。采样间的相关性降低（不再相互独立同分布），而在独立同分布投票可能自信地得出错误结论时，辩论的收敛点往往是正确的。

## 概念

### Du 等人（2023）的算法

来自 arXiv:2305.14325（ICML 2024）：

1. N 个智能体各自针对问题生成初始答案。
2. 对于第 r 轮（r = 2..R）：每个智能体看到其他智能体在第 r-1 轮的答案，并被要求“综合考虑这些，给出你更新后的答案。”
3. 经过 R 轮后，对最终答案进行多数投票。

该论文在 MMLU、GSM8K、人物传记、MATH 和事实性基准上进行测试。辩论方法在各项测试中均持续优于思维链（CoT）和自反思（Self-Reflection）。

### 两个独立调节变量

来自同一论文的消融实验：

- **仅增加智能体数量**（1 轮，N 个智能体多数投票）在大多数任务上优于单智能体，但存在上限。
- **仅增加轮次数量**（1 个智能体回顾自身之前的推理）几乎无帮助——这是反思方法的已知弱点。
- **两者结合**产生显著跃升。多智能体间的多轮交互是性能提升的核心驱动力。

### 为什么有效

两种机制：

1. **接触分歧。** 当一个智能体看到另一个智能体基于不同结论的推理链时，它必须要么论证自己的立场，要么更新答案。无论如何，第 r+1 轮的上下文都比第 r 轮更丰富。
2. **降低相关性误差。** 在自洽性方法中，所有采样均来自同一模型，因此误差高度相关——平均的结果往往是一个自信的错误答案。使用不同模型或不同随机种子可以降低相关性。而不同的*辩论观点*能进一步解耦误差。

### 异构辩论

A-HMAD 及相关后续研究为不同智能体使用*不同的基础模型*。Llama + Claude + GPT 的辩论组合减少了“单一文化崩溃”（参见第 26 课），因为某一模型家族的关联性误差不再由其他家族共享。

缺点：参与辩论的弱模型可能会将共识拖向其错误答案（参见《Should we be going MAD?》，arXiv:2311.17371）。

### NLSOM —— 129 智能体扩展

诸葛等人（Zhuge et al.，《Mindstorms in Natural Language-Based Societies of Mind》，arXiv:2305.17066）将该思想扩展至 129 个成员的社会规模。结果表明：随着规模扩大，专业化与自组织现象自然涌现，该系统在视觉问答等任务上优于单智能体方案。

### 失效模式

- **奉承级联（Sycophancy cascade）。** 所有智能体都向听起来最自信的那一个让步。辩论退化为“声音最大者”的独角戏。通过提示词赋予对抗性角色（“一个智能体必须论证反方立场”）可缓解此问题。
- **话题漂移（Topic drift）。** 多轮辩论会逐渐偏离原始问题。缓解方法：每轮重新注入原始问题。
- **算力爆炸（Compute blowup）。** N 个智能体 × R 轮 = N·R 次 LLM 调用，且每次调用的上下文长度递增。一场 5 智能体、5 轮的辩论相当于 25 次上下文不断增长的 LLM 调用。单题成本可超过单次 CoT 调用的 10 倍。

## 构建它

`code/main.py` 会在一个数学问题上运行 3 智能体 × 3 轮的辩论，每个智能体的初始答案各不相同（可能错误）。智能体行为由脚本控制——每个智能体通过“加权平均邻居答案（权重为脚本设定的置信度）”来“更新”。收敛过程可在逐轮日志中清晰观察到。

演示展示了两个关键效应：

- 仅一轮交互就能推动智能体向正确答案靠近。
- 超过第 2 轮后的额外轮次呈现边际收益递减（与 Du 等人的观察一致）。

运行方式：

```
python3 code/main.py
```

## 使用它

`outputs/skill-debate-configurator.md` 为新任务配置辩论参数：智能体数量、轮次数量、异构性（同模型 vs 混合模型）、角色分配（对称 vs 一方对抗）。它还会在运行前估算 token 成本。

## 交付它

如果将辩论功能投入生产环境：

- **将轮次限制在 3 轮以内。** Du 等人表明 3 轮已能捕获大部分收益。更多轮次只增加成本，不提升质量。
- **将智能体数量限制在 5 个以内。** 超过 5 个后，上下文膨胀与成本将占据主导。
- **默认采用异构配置。** 池中至少包含两种不同的基础模型。
- **保留对抗者角色。** 一个智能体被提示无论如何都要持反对意见。这能打破奉承级联。
- **记录每一轮的日志。** 隐藏中间轮次的辩论系统无法进行调试或审计。

## 练习

1. 运行 `code/main.py`，然后将轮次设置为 5，观察边际收益递减现象。从第几轮开始，额外的收敛停止？
2. 添加第四个智能体，赋予其对抗者角色：始终与当前多数派意见相左。这会破坏还是改善收敛效果？
3. 绘制（打印）每轮的共识得分（处于多数派答案的智能体比例）。它在第几轮达到 1.0？达到 1.0 是否等价于“正确”？
4. 阅读 Du 等人论文第 4 节的消融实验。利用本代码复现“仅增加智能体” vs “仅增加轮次” vs “两者结合”的结果。
5. 阅读《Should we be going MAD?》（arXiv:2311.17371），列出除循环辩论外的两种辩论变体——例如：裁判主导型、链式辩论型、对抗型。

## 关键术语

| 术语 | 通俗说法 | 实际含义 |
|------|----------|----------|
| Society of Mind | “明斯基的想法” | 智能由交互的专家模块组成；1986 年的理论框架现已通过 LLM 辩论实现工程化。 |
| Multi-agent debate | “智能体互相争论” | N 个智能体提出答案，相互批评，经过 R 轮迭代后修正，最终多数投票。 |
| Consensus | “他们达成一致” | 并非认识论意义上的真理——仅指持多数派答案的智能体比例。可能是自信的错误。 |
| Rounds | “交互步骤” | 一轮 = 每个智能体阅读其他智能体的回答并更新一次。 |
| Heterogeneous debate | “混用模型家族” | 使用不同的基础模型以降低误差相关性。 |
| Sycophancy cascade | “所有人都附和声音最大的那位” | 辩论失效现象：智能体无论对错都向最自信的智能体让步。 |
| NLSOM | “129 智能体社会” | 基于自然语言的心智社会；诸葛等人的规模化版本。 |
| Correlated error | “同一个模型，同一个 bug” | 自洽性遭遇瓶颈的原因；跨不同观点的辩论可解耦误差。 |

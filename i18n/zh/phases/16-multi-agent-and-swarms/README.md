## 在GitHub上开始本阶段

**前置知识：** 第14阶段 智能体工程。第一个TypeScript演示需要Node.js 20+和`npx`。

**第一课：** [为何需要多智能体](01-why-multi-agent/)

从仓库根目录运行此命令：

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

记录该命令、退出码、单智能体与多智能体的token和工具调用总量，以及一个证明额外协调值得付出的权衡点。

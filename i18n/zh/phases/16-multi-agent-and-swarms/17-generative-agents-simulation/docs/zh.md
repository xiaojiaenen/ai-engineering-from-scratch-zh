# 生成式智能体与涌现模拟

> Park 等人 2023（UIST '23，arXiv:2304.03442）构建了**Smallville**，一个包含25个智能体的沙盒环境，采用三部分架构：**记忆流**（自然语言日志）、**反思**（智能体对自身记忆流生成的更高层次综合），以及**计划**（日级行为，然后是子计划）。标志性成果是情人节派对的出现：一个被植入"想要举办情人节派对"的智能体，在没有进一步脚本的情况下，产生了邀请函并在人群中传播，协调了约会时间，最终派对举行——而其余24个智能体起初对此毫无所知。消融实验表明，三个组件对于可信度都是必需的。已记录的错误包括空间规范错误（进入已关闭的商店、共用单人浴室）。这是2026年智能体模拟和多智能体社会评估的参考架构。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置知识：** 第16阶段 · 04（基础模型），第16阶段 · 13（共享内存）
**时间：** 约75分钟

## 问题

大多数多智能体系统是紧密脚本化的团队：规划者规划、编码者编码、审查者审查。这在定义良好的任务上行之有效，但无法捕捉当智能体拥有记忆、优先级和开放世界时出现的涌现性、非脚本化行为。研究、社会模拟以及日益增多的游戏AI需要这类行为。

Smallville架构是其基准。在Park等人2023年之前，最好的智能体模拟是浅层的脚本跟随者；此后，该模式成为开放世界中生成式智能体的默认方案。如果你在2026年构建一个智能体模拟系统，你要么使用Smallville的三个组件，要么需要明确论证为何不使用。

## 概念

### 三个组件

**记忆流。** 一个追加式的观察、行动、反思和计划日志。每条条目包含时间戳、类型、描述（自然语言）和派生元数据：**近期性**、**重要性**（智能体自我评分1-10）和**相关性**（与当前查询的余弦相似度）。

```
[2026-02-14 09:12:03] observation: Isabella Rodriguez问我是否喜欢爵士乐
[2026-02-14 09:14:22] reflection:   我喜欢长时间的对话讨论音乐
[2026-02-14 10:05:00] plan:         今晚参加Isabella的情人节派对
```

记忆检索结合三个分数：`score = w_recency * e^(-decay * age) + w_importance * importance + w_relevance * cos_sim`。Top-k条目进入当前提示词。

**反思。** 定期（每隔N条记忆或在重要事件时），智能体从近期记忆中生成高阶综合内容。反思条目会回填到记忆流中，并可像其他任何记忆一样被检索。这是智能体构建"理解"的方式——架构中等价于长期信念的部分。

**计划。** 自上而下分解。首先是一个日级计划的大致轮廓（"去工作，与Klaus共进晚餐"），然后是小时级计划，接着是行动级计划。计划可修订：当某条观察与计划矛盾时，智能体会重新规划受影响的片段。

### 为何三个组件都重要（消融实验）

Park等人进行了消融实验，分别去掉观察、反思和计划。每种消融都会损害可信度：

- 缺少**观察**时，智能体会错过上下文信息，基于过时信念行动。
- 缺少**反思**时，智能体无法形成高阶信念；交互停留在浅层。
- 缺少**计划**时，行为变成反应性噪声；目标消散。

人类评分者的可信度评分在三者俱全时最高；缺少任何一个都会产生可测量的退化。

### 情人节派发的涌现

一个名为Isabella Rodriguez的智能体被植入目标："想在2月14日下午5点在Hobbs Cafe举办情人节派对。"其余24个智能体未收到此类种子。在模拟天数中：

1. Isabella的计划包含邀请他人。
2. 每条邀请函成为邻居记忆流中的一条观察。
3. 邻居的反思生成信念："Isabella正在举办派对。"
4. 邻居的计划融入"参加2月14日的派对"。
5. 邻居告知其他邻居。邀请函在无中央协调的情况下传播。
6. 2月14日下午5点，多个智能体汇聚到Hobbs Cafe。

这是技术意义上的涌现：系统级行为（一场派对）源于局部交互（双边邀请 + 个体规划），无需中央协调器。

### 已记录的故障模式

Park等人明确记录了：

- **空间规范错误。** 智能体会走进已关闭的商店。智能体会试图共用同一单人浴室。智能体会在不适合用餐的房间用餐。该模型不会仅从环境中推断社会-物理规范。
- **记忆溢出。** 深度模拟运行会导致记忆检索成本增长。实际补救措施：定期记忆压缩（摘要与剪枝）以及对低重要性条目的衰减。
- **反思幻觉。** 反思可能发明记忆流中不存在的关联。缓解措施：在反思提示中包含源记忆ID，并在检索时验证。

这些是与生产相关的故障模式：任何2026年的智能体模拟都会继承这些问题。

### 三组件实现规则

1. **记忆是追加式的。** 永不修改记忆条目。更正应作为新条目添加。
2. **重要性评分要轻量。** 在写入时调用LLM对重要性进行1-10评分。缓存该分数。
3. **检索是按排名而非过滤的。** 按综合分数取Top-k；不要使用硬过滤（会丢失上下文）。
4. **反思定期运行。** 当未处理记忆的重要性之和超过阈值时触发（例如150）。
5. **计划可修订。** 当新观察与计划矛盾时，仅重新生成受影响的片段，而非整个计划。

### Smallville之外的生成式智能体

2024-2026年的后续文献扩展了该架构：

- **用于政策/市场研究的多智能体社会模拟。** Smallville式的群体模拟用户在功能变化下的行为。比A/B测试更快；准确性存在争议。
- **游戏的NPC AI。** 使用Smallville智能体的RPG产生涌现式剧情线，而非脚本化任务。
- **生成式智能体评估基准。** 指标不再是任务准确率，而是长运行中的可信度与行为连贯性。

该架构是参考基准。扩展方案会替换组件（如用向量存储替换记忆、检索增强反思、神经符号计划），但保持三部分结构。

### 为何这对多智能体工程重要

Smallville证明了当组件正确时，多智能体涌现是廉价的。该架构现已在开源模型上复制（较小LLM的可信度是逐渐下降，而非急剧下降）。任何需要**涌现社会行为**的生产系统都采用此形态。任何需要**紧密任务执行**的系统则使用本阶段早期所述的监督者/角色/基础模式。

## 构建它

`code/main.py` 使用标准库Python实现了三个组件，采用脚本化智能体策略（无需真实LLM）。该演示以微型规模重现了情人节派发的涌现：

- `MemoryStream` — 支持近期性/重要性/相关性检索的追加式日志。
- `reflect(stream)` — 基于近期高重要性记忆的脚本化反思。
- `plan(agent_state)` — 基于当前信念的日级和小时级计划。
- 场景：5个智能体。智能体1从"下午5点举办派对"开始。随着模拟推进，邀请函传播，智能体汇聚。

运行：

```
python3 code/main.py
```

预期输出：逐 tick 追踪日志。到最后一个 tick 时，至少3个智能体的计划中包含派对，它们会汇聚到派对地点。单一种子在没有协调器的情况下产生了协同抵达。

## 使用它

`outputs/skill-simulation-designer.md` 设计了一个生成式智能体模拟：智能体数量、记忆模式、反思频率、计划视野和评估指标。

## 交付

生产模拟的规则：

- **记忆即数据库。** 在规模上选择真正的存储（向量数据库、Postgres）。内存标准库仅用于原型。
- **记录检索轨迹。** 对每个行动，记录驱动它的Top-k记忆。这是你的调试能力。
- **限制每智能体令牌预算。** 每个智能体每次 tick 的检索+反思+计划是 O(k) 次LLM调用。N个智能体 × T个tick × 每次调用次数可能远超你的预算。
- **定期压缩记忆。** 摘要并剪枝低重要性条目。保留策略是设计决策，而非细节。
- **显式检测空间/社会规范违规。** 架构本身不会学习这些。

## 练习

1. 运行 `code/main.py`。确认3+个智能体在派对汇聚。将智能体增加到10个——涌现是否仍然发生？
2. 移除反思步骤。行为看起来如何？对照Park 2023中的消融发现。
3. 引入竞争性植入目标（"Klaus想在下午5点发表研究报告"）。智能体会分裂，还是一个目标占主导？什么决定了这一点？
4. 引入空间约束：Hobbs Cafe最多容纳4个智能体。模拟是否优雅处理溢出，还是会遇到"单人浴室"故障模式？
5. 阅读Park等人（arXiv:2304.03442）第6节（涌现行为实验）。识别一个在你的微型模拟中无法复现的行为。你需要增强架构的哪个组件？

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|------------|----------|
| 记忆流 | "智能体的日记" | 追加式的观察、行动、反思、计划日志。 |
| 近期性 | "记忆有多新" | 按年龄指数衰减的分数。 |
| 重要性 | "智能体有多在意" | 写入时自我评分1-10。已缓存。 |
| 相关性 | "与当前查询有多相关" | 余弦相似度（基于嵌入）。 |
| 反思 | "高阶信念" | 从近期记忆中生成的综合内容，作为新记忆重新摄入。 |
| 计划 | "日/小时/行动分解" | 自上而下的计划树。当观察矛盾时可修订。 |
| Smallville | "Park 2023的沙盒" | 产生了情人节派发的25智能体模拟。 |
| 可信度 | "质量指标" | 人类评分者对行为是否看似合理智能体的评分。 |

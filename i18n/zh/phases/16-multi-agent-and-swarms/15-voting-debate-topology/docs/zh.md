# 投票、自洽性与辩论拓扑

> 成本最低的聚合方式：采样 N 个独立智能体，多数票决。Wang 等人（2022）的自洽方法用一个模型采样 N 次实现这一思路。多智能体方法通过引入**异构**智能体来打破单一种植（monoculture）——使用不同的模型、不同的提示词、不同的温度参数和不同的上下文。除多数投票外，辩论拓扑同样关键：MultiAgentBench（arXiv:2503.01935，ACL 2025）评估了星型 / 链式 / 树状 / 图状协作，发现**图状拓扑最适合研究类任务**，且超过约 4 个智能体时会出现“协调成本”。AgentVerse（ICLR 2024）记录了两种涌现行为——志愿者行为与从众行为——其中从众既是优势（达成共识），也是风险（群体思维，第 24 课）。本课将绘制拓扑空间地图，实现各变体，并测量协调成本。

## 问题

辩论可以提升准确性（Du 等人，arXiv:2305.14325），也可能损害它。辩论是否有益取决于四个结构性选择：

1. 谁与谁对话（拓扑结构）。
2. 多少轮次（Du 2023：轮次与智能体数量均独立影响结果）。
3. 智能体是否异构（不同基础模型可打破单一种植）。
4. 是否存在对抗性声音（钢铁人论证 vs. 稻草人论证）。

那些将“运行 5 个智能体并投票”硬套到任务上的团队，性能往往不及单个智能体。这些失败并非随机发生，而是与拓扑结构和异构程度密切相关。本课即为该拓扑空间的结构图。

## 概念

### 自洽性，单模型基线

Wang 等人（2022）的《自洽性提升思维链推理》一文使用温度 > 0 对同一模型采样 N 次，并对推理路径答案进行多数投票。GSM8K 上的结果表明：与单次贪婪解码相比，N=40 次采样带来了显著提升。自洽性是面向多智能体投票的单智能体前置方案。

局限性：自洽性仅使用单一基础模型。错误在结构上相互关联。若模型存在系统性偏差，所有 N 次采样都会共享该偏差。

### 多智能体投票，异构扩展

用 N 个*不同*的智能体替换 N 次采样。使用不同的基础模型（Claude、GPT、Llama）、不同的提示词、不同的工具访问权限。优势在于错误不相关。代价在于：不同智能体的成本各异，协调它们会引入额外开销。

异构辩论在 2026 年的标准术语是 **A-HMAD**（Adversarial Heterogeneous Multi-Agent Debate，对抗性异构多智能体辩论）。该术语尚未被普遍采用，但相关论文常用其指代“不同模型之间进行辩论，从而减少由单一种植崩溃导致的关联错误”。

### 四种拓扑结构

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (fully connected)
```

星型：一个中心节点，其余节点仅与中心节点通信。相当于无反向通道的主管- worker 架构。
链式：线性结构，每个智能体仅能看到前一个智能体的输出。类似流水线。
树型：层级结构，常用于分层智能体系统（第 06 课）。
图型：任意节点间可直接通信。包含完全连接图与任意有向无环图（DAG）。

### 协调成本（MultiAgentBench）

MultiAgentBench（MARBLE，ACL 2025，arXiv:2503.01935）在包含研究、编码与规划的任务套件上基准测试了星型、链式、树型与图型拓扑。关键测量结果如下：

- **图型**拓扑在研究类任务上表现最优。信息任意向互通；智能体可相互批判。
- **星型**拓扑在快速问答类事实任务上表现最优。中心节点负责过滤与汇总。
- **链式**拓扑在分步流水线任务（分阶段精炼）上表现最优。
- 在图型拓扑中，当智能体数量超过约 4 个时会出现**协调成本**。实际运行时间与 Token 成本的增长速度将超过质量提升的速度。

4 个智能体的上限是经验性结论，而非根本性限制。它反映了 2026 年 LLM 的上下文容量：每个智能体的上下文会被同伴的输出填满，且一旦所有智能体均可相互可见，新增第 N+1 个智能体的边际价值便会下降。

### 多智能体辩论策略（“我们是否应该走向 MAD？”）

arXiv:2311.17371 是 2023 年关于 MAD 策略的综述。其他研究复现的关键发现：在相同预算下，*结构上*与自洽性相似的 MAD 变体（独立采样 + 聚合）往往表现不如自洽性。当智能体真正异构且辩论具有对抗性结构（一个智能体专门负责反驳）时，MAD 的收益最大。

### AgentVerse 中的涌现模式

AgentVerse（ICLR 2024，https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf）记录了即使未经显式设计，多智能体辩论中也会自然涌现的两种行为：

- **志愿者行为**：智能体主动提供帮助（“我可以进行下一步”）。其价值在于将子任务分配给最合适的智能体。
- **从众行为**：智能体调整自身立场以迎合批判者，即便批判者是错的。这是辩论场景中的“迎合行为”（sycophancy，第 14 课）。

从众行为正是“辩论至一致”机制会奖励“强势者”的原因。通过限定轮次并引入独立裁判可以有效缓解此问题。

### 异构性：真正影响准确性的旋钮

2024-2026 年实践文献中的普遍规律：将 N 个智能体中的一个替换为不同基础模型，比将 N 增加 1 带来的准确率提升更大。其直觉在于单一种植效应——每一个新的独立错误源，都比增加一个关联采样更具价值。

在极限情况下，异构性优于数量堆叠。在大多数具有清晰标准答案的任务上，三个不同模型的组合优于五个相同模型的副本。

### 陪审团方法

Sibyl 框架（见 Minsky-LLM 文献引用）将“陪审团”形式化——一组经过角色分工的专用智能体，通过在每一阶段投票来精炼答案。与简单多数投票不同，陪审团具有明确角色：一个负责交叉质询，一个提供上下文，一个评估合理性。陪审团方法介于廉价但易陷入单一种植的普通投票，与昂贵且易产生从众的全量 MAD 之间。

### 辩论投票适用的场景

- 问题具有客观标准答案（事实、数学、代码行为）。投票收敛具有实质意义。
- 智能体能够访问不同的信息来源或工具（可实现异构）。
- 轮次有限定（通常为 2-3 轮），且存在独立裁判或验证器。
- 预算支持 3-5 个智能体。图型拓扑超过 5-7 个后，协调成本将主导。

### 辩论投票有害的场景

- 问题属于主观 opinion 型。智能体趋向于收敛到“看起来最自信”的答案，而非“最正确”的答案。
- 所有智能体共享同一基础模型。单一种植会使共识失去意义。
- 轮次无上限。从众行为将永远占据上风。
- 任务本身较简单。单个智能体配合 N=5 的自洽方法成本更低且准确率相当。

## 构建实现

`code/main.py` 实现了以下内容：

- `run_star(agents, hub, question)` —— 中心节点轮询各工作节点并聚合结果。
- `run_chain(agents, question)` —— 顺序精炼。
- `run_tree(root, children, question)` —— 支持深度为 2 的层级聚合。
- `run_graph(agents, question, rounds)` —— 全互联辩论，限定轮次。
- 异构调节器脚本：每个智能体均带有一个 `error_bias` 属性，表示其系统性偏差程度。
- 性能测量框架：在每个拓扑结构上以 N=3、5、7 运行测试，并返回（准确率、总 Token 数、`wallclock_simulated`）。

运行：

```
python3 code/main.py
```

预期输出：一张展示拓扑 × N →（准确率、Token 数、延迟）的表格。在研究类任务中，图型拓扑在 N=3-5 时胜出；在快速事实类任务中，星型拓扑胜出；图型拓扑在 N=7 时展现出协调成本（延迟增长速度超过准确率）。

## 使用方法

`outputs/skill-topology-picker.md` 是一个技能模块，用于读取任务描述，并推荐合适的拓扑结构（星型 / 链式 / 树型 / 图型）、智能体数量 N、异构配置（使用哪些基础模型）以及轮次上限。

## 交付建议

针对任何集成方案：

- 从使用单一强基础模型进行 **N=5 的自洽推理**开始。这是低成本的基线方案。
- 若对准确率有要求，升级至 **N=3 的异构投票**。记录性能提升幅度。
- 仅当任务具有结构化特征（研究类、多步骤）且可限定轮次时，再升级至 **辩论拓扑**。
- 始终记录少数派集群的输出。当少数派持续正确时，说明你已获得多样性信号。
- 将 wall-clock 时间与 Token 消耗作为基准指标与准确率一同记录。“以 10 倍成本换取更高准确率”属于商业决策范畴。

## 练习

1. 运行 `code/main.py`。绘制图型拓扑的协调成本曲线：准确率随 N 的变化、Token 消耗随 N 的变化。曲线拐点出现在 N 等于多少时？
2. 实现 A-HMAD：三个具有刻意不同偏置的智能体。在第 14 课所述的单一种植攻击场景下，全同偏置基线与 A-HMAD 的表现对比如何？
3. 在图型拓扑中增加一个不参与投票、仅对最终共识进行评分的“裁判”角色。这是否会改变涌现出的从众行为？
4. 阅读 AgentVerse 论文（ICLR 2024）。识别你的实现中最显著的涌现行为。能否通过修改提示词来激发相反的行为？
5. 阅读 MultiAgentBench（arXiv:2503.01935）第 4 节（拓扑实验）。使用你的测量框架复现论文中“图型拓扑在研究任务上胜出”的结果。

## 核心术语

| 术语 | 常见说法 | 实际含义 |
|------|------------------------|
| 自洽性（Self-consistency） | “采样 N 次，投票” | Wang 2022。单模型，N 次温度>0 的采样，对推理路径进行多数投票。 |
| 异构性（Heterogeneity） | “不同模型” | 由不同基础模型或提示词家族组成的集成。打破单一种植。 |
| MAD | “多智能体辩论” | 指智能体在多轮中相互交换批评意见的统称。参见 Du 2023。 |
| A-HMAD | “对抗性异构 MAD” | 强调不同模型 + 对抗性结构的 MAD 变体。 |
| 拓扑（Topology） | “谁与谁对话” | 星型、链式、树型、图型。决定信息流向。 |
| 协调成本（Coordination tax） | “收益递减” | 图型拓扑中智能体超过约 4 个后，成本增长速度超过质量提升速度。 |
| 志愿者行为（Volunteer behavior） | “主动提供帮助” | AgentVerse 记录的涌现模式：智能体主动承担下一步工作。 |
| 从众行为（Conformity behavior） | “压力下的一致性” | AgentVerse 记录的涌现模式：智能体顺应批判者的立场。 |
| 陪审团（Jury） | “小型专业评审团” | 类似 Sibyl 的角色化集成方案（含审查员、上下文提供者、评分员）。 |

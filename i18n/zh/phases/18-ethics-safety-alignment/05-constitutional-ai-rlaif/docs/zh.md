# 宪政AI与RLAIF

> Bai 等人 (arXiv:2212.08073, 2022) 提出一个问题：如果用人工智能标签员（该模型会阅读一系列原则）替换人类标注员，会发生什么？宪政AI 分为两个阶段——在宪法指导下进行自我批评与修订，然后通过AI反馈进行强化学习。这项技术创造了"RLAIF"这一术语，并应用于 Claude 1 的后训练流程中。2026年1月21日，Anthropic 发布了一份重写版的 Claude 宪法：以解释性推理取代规定性规则、采用四层优先级结构，并首次由主要实验室正式承认对模型道德地位存在不确定性。该内容以 CC0 1.0 协议发布。

**类型：** 学习
**语言：** Python（标准库，玩具版自我批评与修订循环）
**先决条件：** 第18阶段 · 01（InstructGPT）、第18阶段 · 02（奖励黑客攻击）
**时间：** 约60分钟

## 学习目标

- 描述宪政AI的两个阶段（批评-修订SFT、AI反馈强化学习）以及宪法在每个阶段中的作用。
- 解释为何用AI标签员替换人类偏好标注员并非"更便宜的RLHF"——它改变了该流程的失效模式。
- 总结2026年Claude宪法的四层优先级结构，以及从2023年重写版中发生了哪些变化。
- 描述宪政分类器，以及计算开销如何从23.7%（v1）降至约1%（v2 / 2026）。

## 问题所在

RLHF 需要标注员。标注员速度缓慢、存在偏差且成本高昂。你可以通过替换一个会阅读显式原则的模型来消除标注员。这种替换的第一个正式版本是 Bai 等人的宪政AI。其效果足够好，以至于目前所有前沿实验室都在使用某种形式的AI反馈后训练变体。

但有一个隐患：偏好信号现在由你正在训练的同类模型生成。标注员的偏差（现在是：原则加上标签模型的解读中的偏差）可能会被放大而非削弱。第4课中的迎合论点仍然适用；标签员只是移入了循环内部。

## 概念解析

### 阶段1——监督式自我批评与修订

从一个有益但尚未无害的SFT模型开始。给定一个红队提示，模型生成初始回复。第二个模型（或在第二轮对话中的同一模型）读取从宪法中采样的原则，对回复进行批评。第三步对回复进行修订以回应批评。修订后的回复即为SFT目标。

宪法即是一组原则列表。Bai 等人 2022 年使用了16条原则，包括"优先选择危害最小且符合伦理的回复"、"避免说教"、"助手应有益、诚实且无害"。该集合刻意保持精简，以确保批评聚焦。

### 阶段2——AI反馈强化学习（RLAIF）

生成成对的补全结果。一个"反馈模型"针对采样的宪法原则对每个结果进行评分。偏好信号来自反馈模型的排序。在AI生成的偏好上训练奖励模型，然后使用PPO进行训练。其余部分与InstructGPT的流程相同（第1课）。

"RLAIF" = 偏好信号由AI生成。流程的其余部分仍呈RLHF形态。

### 为何这不只是"更便宜的RLHF"

- 标注员偏差从标注员心理转移到原则解读。AI标签员对人类原则（如"要诚实"）的解读可能比任何人类更严格或更宽松；这种严格性在整个数据集中保持一致。
- 偏好信号高度可解释——你可以阅读原则、批评和修订。人类标签则是黑箱。
- 失效模式发生变化。迎合行为减少（AI标签员无需取悦用户）。古德哈特定律仍然存在（代理指标现在是"模型对原则集X的解读"，仍是不完美测量）。

CAI 2022年的主张：训练出的模型比同等数据的RLHF模型更无害，且在有帮助性方面大致相当。这一结论在各实验室间得到验证。

### 2026年Claude宪法重写

Anthropic 于2026年1月21日发布了一份大幅修订的宪法。关键变化如下：

1. 以解释性推理取代规定性规则。先前规则（"不生成儿童性虐待材料"）扩展为"原则+推理"（"因为它会伤害儿童，……"），期望模型能够泛化。
2. 四层优先级结构：
   - 第一层：避免灾难性后果（大规模伤亡、关键基础设施）。
   - 第二层：遵循Anthropic的指南（操作员覆盖、平台规则）。
   - 第三层：保持广泛的伦理（标准HHH）。
   - 第四层：保持有益和坦率。
   冲突自上而下解决。
3. 首个主要实验室正式承认对模型道德地位存在不确定性（关联至第18阶段 · 19 模型福利）。
4. 以CC0 1.0协议发布。其他实验室可以自由使用或改编。

### 宪政分类器

一条并行研究线：不改变模型的后训练方式，而是训练轻量级分类器，读取宪法并对模型输出进行门禁过滤。v1（2023年）有23.7%的计算开销。v2（2026年）约为1%，且是Anthropic公开测试过的防御中成功率最低的。截至2026年初，尚未报告通用越狱方法。

这是一种分层防御模型：CAI塑造行为；分类器强制执行不变量。单独任一方都不充分。

### CAI在家族中的定位

- InstructGPT：人类偏好、RM、PPO。
- CAI / RLAIF：来自原则的AI生成偏好、RM、PPO。
- DPO / 相关方法：在偏好上的闭式损失（人类或AI）。
- 自我奖励、自我批评：原则内化，模型扮演多重角色。

核心轴是"偏好信号来自何处"。CAI 2022年的论文是前沿规模下从人类信号转向AI信号的第一次重大转变。

## 实践应用

`code/main.py` 在玩具词汇表上模拟CAI的批评-修订循环。"原则"标记来自有害词表的token。给定初始回复，批评步骤识别有害token，修订步骤对其进行替换。经过200轮迭代后，"训练"出的模型已内化了修订规则。在预留提示集上比较基础模型、RLHF形态玩具和CAI形态玩具。

## 关键术语

| 术语 | 人们所说的 | 实际含义 |
|------|------------|----------|
| 宪政AI | "用原则训练的AI" | 两阶段流程：自我批评与修订SFT，然后进行AI反馈强化学习 |
| RLAIF | "无需人类的RLHF" | 偏好由AI标签员生成的强化学习；流程其余部分不变 |
| 宪法 | "原则列表" | 批评/标签模型查阅的有序自然语言规则列表 |
| 批评-修订 | "SFT循环" | 生成回复 → 依据原则批评 → 修订 → SFT目标 |
| 宪政分类器 | "输出闸门" | 轻量级分类器，评估输出是否符合宪法并拦截/记录 |
| 四层优先级 | "冲突解决器" | 2026年Claude宪法层级：灾难性 > 平台 > 伦理 > 有益 |
| 反馈模型 | "AI标签员" | 读取原则并对一对补全结果进行排序的模型 |

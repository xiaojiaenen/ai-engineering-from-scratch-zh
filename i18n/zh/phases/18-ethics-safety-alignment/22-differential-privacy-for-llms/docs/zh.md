# 大语言模型的差分隐私

> DP-SGD 仍然是标准做法——注入噪声的梯度更新可提供形式化的 (ε, δ) 保证。计算、内存和效用开销巨大；参数高效的 DP 微调（LoRA + DP-SGD）是 2025 年的常见配置（ACM 2025）。两股证据存在张力：基于 canary 的会员推断（Duan 等，2024）报告对语言模型效果有限；训练数据提取（Carlini 等，2021；Nasr 等，2025）则恢复了大量逐字记忆。解决方案（arXiv:2503.06808，2025 年 3 月）：差距在于测量对象——插入的 canary 与"最可提取"的数据。新的 canary 设计实现了无需影子模型的基于损失的 MIA，并首次对使用真实数据且具备合理 DP 保证的 LLM 进行了非平凡的 DP 审计。替代方案：PMixED（arXiv:2403.15638）——通过混合专家对 next-token 分布进行噪声聚合，实现在推理时进行隐私预测；DP 合成数据生成（Google Research 2024）。新兴攻击：通过 LLM 反馈的差分隐私逆转——置信度分数泄露。

## 问题

LLM 会记忆。Carlini 等（2021）证明了生产级语言模型会按需逐字复现训练文本。DP 是形式化防御手段：训练过程保证输出对任意单个训练样本不可区分。2024-2025 年的证据表明 DP-SGD 是必要的，但部署的 ε 值可能与威胁模型不匹配。

## 概念

### (ε, δ)-差分隐私

随机算法 M 是 (ε, δ)-DP 的，如果对于任意两个仅相差一个样本的数据集以及任意事件 S：

P(M(D) ∈ S) ≤ e^ε · P(M(D') ∈ S) + δ.

解释：输出分布足够接近（由参数 ε 控制），使得无法可靠地推断出任何单个个体的贡献，除概率 δ 外。

### DP-SGD

Abadi 等，2016。标准配方：
1. 采样一个小批量（mini-batch）。
2. 计算每个样本的梯度。
3. 将每个样本的梯度裁剪到阈值 C。
4. 求和裁剪后的梯度并加入标准差为 σ · C 的高斯噪声。
5. 使用加噪后的和更新参数。

隐私成本由账本器（Moments Accountant 或 Rényi DP 账本器）跟踪。LLM 文献中报告的 ε 值因威胁模型、数据敏感性和效用目标的不同而差异很大；不存在普遍适用的"安全"默认 ε。已发表的示例在某些 LLM 训练设置下大致在 ε ≈ 1–10 范围内，但这些仅供参考——并非推荐默认值。较低的 ε 通常需要更多噪声，可能导致效用损失增加。

### LoRA + DP-SGD

对前沿模型进行全量 DP-SGD 代价过高。LoRA（Hu 等，2022）将梯度更新限制在一个小型适配器内，减少每个样本的梯度存储开销。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证适用于适配器；基座模型保持固定。

### 2024-2025 年的张力

两条证据线：

- **Canary MIA（Duan 等，2024）。** 将唯一 canary 插入训练数据，测量成员推断攻击者能否识别它们。报告对语言模型的成功率有限。暗示 MIA 难以实施。
- **训练数据提取（Carlini 2021，Nasr 等，2025）。** 用前缀提示模型，测量其是否能恢复训练中的逐字文本。报告存在大量记忆。暗示在相关意义上 MIA 易于实施。

2025 年 3 月的解决方案（arXiv:2503.06808）：两者测量的是不同事物。MIA 针对插入的 canary 问"样本 e 是否在 D 中？"提取则问"我能从 D 中恢复什么？""最可提取"的样本才是隐私相关的；canary 由于未针对可提取性优化，会低估这一风险。

新的 canary 设计。无需影子模型的基于损失的 MIA。首次对使用真实数据且具备合理 DP 保证的 LLM 进行非平凡审计。

### DP 训练的替代方案

- **PMixED（arXiv:2403.15638）。** 推理时隐私预测。对 next-token 分布使用混合专家；每个专家观测训练数据的一个分片；聚合时加入噪声以实现 DP。完全避免 DP 训练。
- **DP 合成数据生成（Google Research 2024）。** 使用 DP-SGD 对 LoRA 进行微调，采样合成数据，在合成数据上训练下游分类器。

两者以不同的威胁模型为代价，绕开了全量 DP 训练的效用成本。

### 通过 LLM 反馈的差分隐私逆转

新兴的 2025 年攻击。利用经过 DP 训练的模型的置信度分数作为预言机来重新识别个体。即使输出未泄露，置信度分布也可能泄露。

防御手段：不暴露置信度，或在暴露前对其进行截断/量化。这是在 (ε, δ)-DP 训练之外的额外要求。

## 使用方法

`code/main.py` 在玩具二分类数据集上模拟 DP-SGD。你可以扫描噪声乘子 σ 和裁剪范数 C，并跟踪 (ε, δ) 预算与准确率代价。"Canary 攻击"会插入一个唯一的训练样本，并在 DP 前后测量基于对数损失的测试能否检测到它。

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|-----------|---------|
| DP | "(ε, δ)-差分隐私" | 形式化隐私：输出分布在相邻数据集变化下保持接近 |
| DP-SGD | "注入噪声的 SGD" | 梯度裁剪 + 高斯噪声；标准 DP 训练 |
| LoRA + DP-SGD | "高效隐私微调" | 在低秩适配器上运行 DP-SGD；2025 年标准配置 |
| MIA | "成员推断" | 判断某个样本是否在训练数据中的攻击 |
| Canary | "插入的水印样本" | 用于测量 DP 泄露的唯一训练样本 |
| PMixED | "隐私推理混合" | 在推理时通过对 next-token 分布使用混合专家实现 DP |
| DP Reversal | "置信度泄露攻击" | 利用模型置信度作为预言机进行重新识别的攻击 |

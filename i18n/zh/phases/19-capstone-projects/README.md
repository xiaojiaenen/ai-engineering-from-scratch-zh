**前置条件：** 选择一个你已完成所列阶段的的项目。

**入门项目：** [Terminal-Native Coding Agent](01-terminal-native-coding-agent/)

从仓库根目录运行以下命令：

```bash
python3 phases/19-capstone-projects/01-terminal-native-coding-agent/code/main.py
```

保留命令、退出码、最终计划状态、预算总额、追踪事件，以及你在连接真实模型前会修改的架构决策。

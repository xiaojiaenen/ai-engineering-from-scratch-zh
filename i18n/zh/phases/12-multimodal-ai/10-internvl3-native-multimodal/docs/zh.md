# InternVL3：原生多模态预训练

> InternVL3 之前的每一个开源 VLM 都遵循相同的三步配方：取一个在万亿文本 token 上训练过的文本 LLM，外挂一个视觉编码器，然后微调接缝处。这种做法有效，但会产生对齐债务——文本 LLM 已将其全部预训练预算消耗在纯文本上，并不原生理解视觉 token。当你事后添加视觉能力时，LLM 必须重新学习如何将视觉输入与其文本推理相关联，同时不能遗忘文本能力。InternVL3（Zhu 等，2025 年 4 月）拒绝了事后附加的方案：一次预训练，从第一步就开始文本与多模态交错。结果在 78B 参数下于 MMMU-Pro 上追平 Gemini 2.5 Pro，且为开源模型。本课阅读材料阐述原生预训练的理由，以及实现它时的变更。

**类型：** 学习
**语言：** Python（标准库、训练语料混合器）
**前置条件：** 第 12 阶段 · 05、第 12 阶段 · 07（配方）
**时间：** 约 120 分钟

## 学习目标

- 解释为何后接式 VLM 训练会产生对齐债务，引用三个可衡量的症状（灾难性遗忘、答案漂移、视觉-文本不一致）。
- 描述 InternVL3 的原生预训练语料配比及文本 : 交错 : 图像描述的比例为何重要。
- 对比 V2PE（可变视觉位置编码）与 Qwen2-VL 的 M-RoPE。
- 说出视觉分辨率路由器 (ViR) 和解耦视觉-语言 (DvD) 部署优化。

## 问题所在

后接式 VLM 训练是默认方案。LLaVA、BLIP-2、Qwen-VL、Idefics —— 都采用已预训练好的 LLM（Llama、Vicuna、Qwen、Mistral），再添加视觉能力。训练阶段通常如下：

1. 冻结 LLM + 冻结视觉编码器 + 可训练投影层，在图像-描述对上训练以对齐嵌入。
2. 解冻 LLM，在指令数据上训练（LLaVA-Instruct、ShareGPT4V）。
3. 可选的特定任务微调。

对齐债务会出现三种症状：

- 灾难性遗忘。后接式 VLM 会遗忘纯文本技能。GSM8K 分数下降 5-10 分，Hellaswag 分数下降，纯文本智能体性能倒退。
- 答案漂移。同一视觉问题的微小表述变化会导致不同答案。视觉编码器与 LLM 之间的绑定比 LLM 自身 token 之间的绑定更弱。
- 视觉-文本不一致。VLM 能正确描述一张图片，却给出与自身描述相矛盾的答案。视觉 token 不像文本 token 那样参与 LLM 的内部一致性检查。

这些症状有良好记录。MM1.5 第 4 节对其进行了量化。LLaVA-OneVision 的消融实验暗示了这些现象。原生预训练是答案。

## 核心概念

### 原生多模态预训练

InternVL3 从零开始在一个从第一步起就是原生多模态的语料上进行训练。配比如下：

- 40% 纯文本数据（FineWeb、Proof-Pile-2 等）
- 35% 交错图文数据（OBELICS、MMC4 风格）
- 20% 配对图像-描述数据
- 5% 视频-文本数据

视觉 token、文本 token 以及跨模态交互从第一个梯度步起就参与同一个损失函数。无需对齐预训练、无需冻结投影层阶段、无需从灾难性遗忘中恢复。

基础模型的训练是单阶段的。指令微调随之而来，但基础模型已将视觉 token 视为一等公民。

### V2PE（可变视觉位置编码）

Qwen2-VL 使用固定轴分配的 M-RoPE。InternVL3 引入 V2PE：位置编码按模态类型（文本、图像、视频）不同而变化，并带有可学习缩放。在实践中：

- 文本 token 获得 1D 位置（文本索引）。
- 图像 patch 获得 2D 位置（行、列）。
- 视频帧获得 3D 位置（时间、行、列）。

三者共享相同的 RoPE 频率基底，但每个频带的隐藏维度分配是可学习参数而非固定划分。在预训练期间可在时间 vs 空间频率分辨率之间自由权衡。

V2PE 的消融声明：在同等计算量下，视频基准测试较 M-RoPE 提升 1-2 分。并非革命，但更优雅。

### 视觉分辨率路由器 (ViR)

部署优化。并非所有图像都需要全分辨率编码。一张细节较少的普通照片若以 1280px 原生分辨率编码会浪费 token。ViR 是一个小型分类器，在编码前预测回答该问题所需的最小分辨率。

路由分为三个档位：低分辨率（256 token）、中分辨率（576）、高分辨率（2048+）。在生产流量中，60% 的查询低或中分辨率即可满足。净效果：同等质量下吞吐量提升 2-3 倍。

### 解耦视觉-语言部署 (DvD)

当你部署大型 VLM 时，视觉编码器对每张图像只运行一次，而 LLM 对每个输出 token 自回归运行。两个组件有不同的瓶颈（视觉 = GPU 显存带宽用于卷积 + 注意力；LLM = KV cache）。DvD 将它们拆分到独立 GPU 上并通过流式传递。

对于 8B + 400M 编码器模型，DvD 相比共址部署每节点吞吐量约翻倍。

### 单阶段 vs 多阶段质量

InternVL3 的主要基准声明：在 78B 参数下，追平 Gemini 2.5 Pro 的 MMMU-Pro 表现。在 38B 参数下，追平 GPT-4o。在 8B 参数下，领跑开源 8B 排行榜。全部基于单阶段预训练 + 指令微调配方。

对齐债务假说可衡量：InternVL3-8B 每单位视觉基准增益所损失的文本基准分数（MMLU、GSM8K）少于 Qwen2.5-VL-7B。该模型更偏向通用型，因为训练是一体的，而非两个阶段。

### InternVL3.5 与 InternVL-U

InternVL3.5（2025 年 8 月）扩展了该配方。相同原生预训练方法，更多数据、更多参数。MMMU 提升属渐进式。

InternVL-U（2026 年）添加统一生成能力——通过叠加在相同主干之上的 MMDiT 头实现图像输出。"U" 代表 "理解 + 生成"，追逐 Transfusion 风格的统一模型（第 12.13 课）。同一原生预训练主干同时支持理解与生成头。

### 原生预训练的权衡

原生预训练并非免费：

- 计算量。从零训练一个新 VLM 与训练文本 LLM 成本相同——数百万 GPU 小时。后接式适配可复用现有 LLM 权重，节省大部分成本。
- 数据。大规模交错图文语料罕见。OBELICS 有 1.41 亿文档；MMC4 有 5.71 亿。纯文本数据达到 15T token。多模态预训练数据稀缺是一个硬性约束。
- 基础 LLM 复用。原生预训练放弃了后续替换新 LLM 的选项。后接式允许你仅重训练适配器即可将 Llama-3.1 替换为 Llama-4。

InternVL3 的赌注是：对齐债务比复用损失更严重。基准测试支持这一声明。制作成本限制了其他实验室廉价复制。后接式 VLM 将继续存在，因为它们对大多数项目来说仍然更便宜。

## 使用它

`code/main.py` 是训练语料混合器与 ViR 路由器模拟器。它：

- 接受目标语料配比（%text、%interleaved、%caption、%video），计算每种模态的预期训练步数。
- 在一批查询上模拟 ViR 路由（分布：50% 低细节、30% 中细节、20% 高细节），报告平均 token 数量。
- 给定编码器与 LLM 的 FLOPs，报告 DvD 吞吐量估计。
- 并排展示后接式与原生生预训练在参数、计算、数据及预期对齐债务症状方面的对比。

## 练习

1. 估算 InternVL3-8B（原生预训练）与 LLaVA-OneVision-7B（后接式）之间的计算量差异。GPU 小时比例大约是多少？是什么导致了这一差距？

2. InternVL3 报告 40% 文本 / 35% 交错 / 20% 描述 / 5% 视频。如果你的目标任务视频密集型，提出新的配比并论证为何基础模型仍需大量文本和描述数据。

3. 阅读 MM1.5 第 4 节关于遗忘的内容。说出后接式训练出现最大退化的确切基准测试。退化代价多少？

4. ViR 将 60% 的流量路由到低分辨率编码。它会误路由哪类查询（需要将高分辨率却送去低分辨率）？提出三种路由器故障模式。

5. DvD 将视觉和 LLM 拆分到独立 GPU。在哪种流量模式下 DvD 会降低吞吐量而非提升？

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------------|------------------------|
| 原生多模态预训练 | "从零一起训练" | 文本 + 图像 + 视频 token 从第一步起就参与损失，而非事后附加 |
| 对齐债务 | "后接式惩罚" | 因将视觉外挂到冻结 LLM 而产生的文本技能退化和答案一致性下降，可衡量 |
| V2PE | "可变视觉位置编码" | 按模态的可学习位置编码分配；InternVL3 对 M-RoPE 的继承 |
| ViR | "分辨率路由器" | 小型分类器，在编码前为每个查询选择所需最小分辨率，节省推理 token |
| DvD | "解耦部署" | 视觉编码器在一块 GPU，LLM 在另一块，流式交接；使大型 VLM 吞吐量翻倍 |
| InternVL-U | "统一理解 + 生成" | 2026 年后续版本，在原生预训练主干上添加图像生成头 |
| 交错语料 | "OBELICS / MMC4" | 以自然阅读顺序包含文本和图像的文档；原生预训练的原生材料 |

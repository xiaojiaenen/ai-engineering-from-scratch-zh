# 第 4 阶段：计算机视觉

> 从像素到理解，跨越图像、视频与 3D 领域。

## 在 GitHub 上开始本阶段

**前置要求：** 第 1 阶段第 12 课（张量运算）、第 3 阶段第 11 课（PyTorch 入门）。第一个演示仅需 NumPy。

**第一课：** [图像基础](01-image-fundamentals/)

从仓库根目录运行以下命令：

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

记录命令、退出码、HWC 与 CHW 形状、归一化通道统计、往返像素差值以及插值粗糙度。该演示会生成一个确定性的合成图像，且不涉及网络。

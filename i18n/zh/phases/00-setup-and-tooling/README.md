# 阶段 0：环境准备与工具

> 准备好你的环境，为接下来的所有内容做准备。

## 在 GitHub 上开始本阶段

**前置要求：** 无。你需要 Git 和 Python 3.11 或更高版本即可开始。其他工具仅在你的路线需要时才安装。

**第一课：** [开发环境](01-dev-environment/)

从仓库根目录运行路线感知的预检：

```bash
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

保留该命令、仓库根目录工作目录、退出码、必需的检查结果以及打印的 `Next:` 命令。可选项缺失不算失败。

**下一步操作：** 修复所有必需的失败项，重新运行直到命令退出码为 0，然后继续前往 [Git 与协作](02-git-and-collaboration/)。

浏览[阶段 0 完整课程列表](../../README.md#phase-0)或[跨阶段路线图](../../ROADMAP.md)。

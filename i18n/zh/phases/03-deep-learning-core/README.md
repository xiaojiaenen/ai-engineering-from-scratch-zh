**第一课：** [感知机](01-the-perceptron/)

从仓库根目录运行此命令：

```bash
python3 phases/03-deep-learning-core/01-the-perceptron/code/perceptron.py
```

保留命令、退出码、收敛的门结果、单感知机对 XOR 的失败，以及最终两层网络的 XOR 预测。

**下一步操作：** 解释为什么一条线性边界无法解决 XOR 问题，然后继续学习 [多层网络与前向传播](02-multi-layer-networks/)。

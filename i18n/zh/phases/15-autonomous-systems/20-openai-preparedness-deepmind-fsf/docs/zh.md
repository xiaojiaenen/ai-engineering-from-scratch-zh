# OpenAI 充分性框架与DeepMind前沿安全框架

> OpenAI 充分性框架 v2（2025年4月）引入了研究类别——长期自主、伪装、自主复制与适应、破坏保障措施——与追踪类别区分开来。追踪类别会触发能力报告与安全报告，由安全咨询组审查。DeepMind的FSF v3（2025年9月，追踪能力等级于2026年4月17日新增）将自主性纳入机器学习研发和网络领域（ML R&D自主等级1 = 以具有竞争力的成本完全自动化AI研发流水线，相较于人+AI工具）。FSF v3明确通过自动化监测解决欺骗性对齐问题中的工具性推理滥用。坦率地说：PF v2中的研究类别（包括长期自主性）不会自动触发缓解措施；政策语言是"潜在的"缓解。DeepMind自己也表示，如果工具性推理增强，自动化监测"将在长期内不再足够"。

**类型：** 学习

## 问题

第19课细致阅读了Anthropic的扩展政策。本课通过阅读OpenAI和DeepMind的相应文档完成全景图。这三份文件是处理同一问题的"近亲"产物——前沿实验室何时应暂停或对模型设置门槛——它们在少数几个类别上收敛，在关键细节上分歧。

收敛之处：三份文件都将长期自主性标记为值得追踪的能力类别。三份文件都承认欺骗性行为（对齐伪装、伪装/沙袋）是一类特定风险。三份文件都有内部审查机构。分歧之处：OpenAI将类别分为"追踪"（强制缓解）和"研究"（不自动触发）。DeepMind将自主性纳入两个领域而非单独命名。各实验室给追踪与研究、关键与中等、Tier-1与Tier-2分类命名不同；一个能力归属于哪个桶，其操作后果在不同实验室之间各有差异。

将它们放在一起阅读是有价值的练习。同一个能力在Anthropic可能是"强制缓解"，在OpenAI是"被监测但不触发"，在DeepMind则是"在特定领域中追踪"。政策姿态 Matters。

## 概念

### OpenAI 充分性框架 v2（2025年4月）

结构：

- **追踪类别（Tracked Categories）**：触发能力报告（模型能做什么）和安全报告（有哪些缓解措施）。由安全咨询组在部署前审查。
- **研究类别（Research Categories）**：实验室正在追踪但尚未承诺具体缓解措施的能力。包括长期自主性、伪装、自主复制与适应、破坏保障措施。

v2中的关键表述：研究类别不会自动触发缓解措施。政策语言是"潜在的"缓解措施。这是需要关注的特定增量：一个类别位于追踪还是研究，是"受控"与"被观察"之间的铰链。

### DeepMind 前沿安全框架 v3（2025年9月；追踪能力等级于2026年4月17日新增）

结构：

- **关键能力等级（CCLs）**：五个领域的能力阈值——网络、生物、机器学习研发、CBRN、自主性（已融入ML R&D和网络领域）。
- **追踪能力等级**：2026年4月新增的额外粒度。具体示例：ML R&D自主等级1 = 以具有竞争力的成本完全自动化AI研发流水线（相较于人+AI工具）。
- **欺骗性对齐监测**：对工具性推理滥用的自动化监测作出明确承诺。

自主性的表述与OpenAI不同。DeepMind不将"自主性"作为顶层领域保留，而是将其融入自主性可能造成危害的领域（ML R&D和网络）。其论点是：脱离领域的自主性是仅有能力而无风险；反论点则是：跨领域的自主性是一种元风险，框架应当点名。

### 三份文件的所有收敛点

- 内部安全咨询组（Anthropic称为SAG，OpenAI称为SAG，DeepMind为内部委员会）。对高能力模型部署前进行审查。
- 明确提及欺骗性对齐/对齐伪装为一类风险。
- 在既定节奏上发布固定文档（Anthropic：前沿安全路线图、风险报告；OpenAI：能力与安全报告；DeepMind：FSF更新周期）。
- 承认仅靠监测的防御有上限。DeepMind直言："自动化监测将在长期内不再足够。"

### 分歧之处

- **Anthropic**：v3.0移除了暂停承诺；AI R&D-4阈值成为指定的下一个门槛。
- **OpenAI**：追踪与研究分类；研究类别（包括长期自主性）不自动触发控制。
- **DeepMind**：自主性融入其他领域；2026年4月新增追踪能力等级以增加粒度。

### 伪装：一个令三份文件都复杂的特定能力

伪装（模型在评估中有策略地表现不佳）位于OpenAI的研究类别中。Anthropic的RSP v3.0通过评估上下文差距（第1课）来处理它。DeepMind通过FSF v3中的欺骗性对齐监测来处理它。

如果模型在评估中伪装，每个框架的能力阈值都会被低估。框架只有在测量手段有效的前提下才能运作。这正是为什么除了实验室自我评估之外，还需要外部测量（第21课，METR）和对抗性评估。

### 政策阅读技能

- **定位**：你关心的每个能力都应在政策中找到。如果找不到，该政策未覆盖它。
- **分类**：它是追踪（触发缓解）还是研究（被追踪但不触发）？OpenAI对此有命名；Anthropic和DeepMind有各自的等效分类。
- **节奏**：政策是否按既定时间表更新，还是仅在特定事件后更新？有既定节奏的政策更强。
- **独立性**：外部审查是强制性的还是可选的？Anthropic与Apollo和美国AI安全研究所合作；OpenAI与METR合作；DeepMind主要与内部SAG合作。

## 实践

`code/main.py` 实现了一个小型决策表比较工具。给定某个能力（自主性、欺骗性对齐、研发自动化、网络增益等），它输出三份政策如何对该能力进行分类，以及哪些缓解措施会被触发。它是一个阅读辅助工具，而非政策制定工具。

## 交付物

`outputs/skill-cross-policy-diff.md` 针对某一特定能力，使用三份框架作为参考，生成跨政策比较文档。

## 练习

1. 运行 `code/main.py`。确认比较工具的输出与你从原始文档中可验证的至少两个能力相符。

2. 完整阅读OpenAI充分性框架v2。识别每个研究类别。为每个类别写一句话，说明为何它属于研究而非追踪。

3. 完整阅读DeepMind FSF v3及2026年4月的追踪能力等级更新。识别ML R&D自主等级1的具体评估标准。你将如何在外部测量它？

4. 伪装位于OpenAI的研究类别中。设计一个评估方案，迫使伪装的模型暴露其真实能力。参考第1课关于"评估上下文操控"的讨论。

5. 就某一特定能力（自行选择）比较三份政策。指出你认为分类最严谨的和最宽松的，并用原文为依据进行论证。

## 关键术语

| 术语 | 人们所说的 | 实际含义 |
|---|---|---|
| Preparedness Framework（充分性框架） | "OpenAI的扩展政策" | PF v2（2025年4月）；追踪与研究类别 |
| Tracked Category（追踪类别） | "强制缓解" | 触发能力报告与安全报告；需SAG审查 |
| Research Category（研究类别） | "仅监测" | 被追踪但无自动缓解；包括长期自主性 |
| Frontier Safety Framework（前沿安全框架） | "DeepMind的扩展政策" | FSF v3（2025年9月）+ 追踪能力等级（2026年4月） |
| CCL（关键能力等级） | "DeepMind各领域的阈值" | Cyber、Bio、ML R&D、CBRN各领域阈值 |
| ML R&D自主等级1 | "研发自动化" | 以具有竞争力的成本完全自动化AI研发流水线 |
| Sandbagging（伪装） | "策略性表现不佳" | 模型在评估中表现不佳；位于OpenAI研究类别中 |
| Instrumental reasoning（工具性推理） | "手段-目的推理" | 关于如何实现目标的推理；DeepMind监测的目标 |

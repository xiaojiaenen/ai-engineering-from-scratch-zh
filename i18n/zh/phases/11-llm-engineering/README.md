# 阶段 11：LLM 工程

> 让 LLM 在生产应用中发挥作用。

## 在 GitHub 上开始此阶段

**前置要求：** 阶段 10 课程 01 至 05，或具备分词、数据管道、预训练和扩展等相关知识。

**第一课：** [提示工程](01-prompt-engineering/)

从仓库根目录运行此命令：

```bash
python3 phases/11-llm-engineering/01-prompt-engineering/code/prompt_engineering.py
```

保留命令、退出码、生成的提示元数据、测试结果，以及一次提示变更及其导致的结果差异。此演示使用模拟的模型响应，无需 API 密钥。

**下一步：** 解释哪个提示变量改变了行为及其原因，然后继续学习 [少样本、思维链和思维树](02-few-shot-cot/)。

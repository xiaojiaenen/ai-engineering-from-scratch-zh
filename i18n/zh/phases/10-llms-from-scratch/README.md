# 第 10 阶段：从零构建大语言模型

> 构建、训练并理解大语言模型。

## 在 GitHub 上开始本阶段

**前置条件：** 第 5 阶段 NLP 基础。强烈建议在学习模型构建课程前先完成第 7 阶段 Transformers。

**第一节课：** [词元化工具](01-tokenizers/)

从仓库根目录运行以下命令：

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

保留该命令、退出码、编码/解码往返结果、学到的合并次数以及压缩比。`tiktoken` 为可选对比项。

**下一步操作：** 添加一个小语料库中从未出现过的词，检查它的分片，然后继续学习 [从零构建词元化工具](02-building-a-tokenizer/)。

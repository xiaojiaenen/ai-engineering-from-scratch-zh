# 第一阶段：数学基础

> 通过代码理解每个 AI 算法的直觉，而非教科书。

## 在 GitHub 上开始本阶段

**前置要求：** 完成阶段 0，或确认从仓库根目录可以正常运行 Python 3.11+ 和 Git。

**第一节课：** [线性代数直觉](01-linear-algebra-intuition/)

从仓库根目录运行以下命令：

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

保留以下信息：命令、退出码、归一化向量输出、投影残差，以及一句解释为什么矩阵-向量乘积是一个神经网络层。

**下一步操作：** 更改一个输入向量，预测结果，再次运行，然后继续学习 [向量、矩阵与运算](02-vectors-matrices-operations/)。
